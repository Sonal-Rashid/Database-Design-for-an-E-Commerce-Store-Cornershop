# Database design for an E-Commerce Store - Cornershop

## 📊 Project Overview 
The aim of this project is to design and create a relational database for an e-commerce company called Cornershop.
Cornershop is a merchandise store for coders selling hoodies, mugs, stickers, notebooks, and accessories. 

This project demonstrates:
- Database design, 
- Table relationships, 
- Foreign keys, 
- Realistic demo data, 
- Business-oriented SQL analysis

## 🔄 Project Workflow
### Step 1: Database and Table Creation
The Cornershop database and the following tables were created
- customers
- products
- orders
- order_items
- payments
  
### Step 2: Data Population
In this stage all tables were populated with demo data.

### Step 3: Data Analysis
As the final step, SQL queries were used to perform calculations and analyze business performance.
The following business questions were answered:
- How many unique products and categories are available?
- What is the total revenue generated?
- What is the revenue generated by product and category?
- Who are the top customers by total spending?
- What are the best-selling products?
- How many orders were cancelled?
- What is the monthly revenue trend?
- How many orders are there by status?
- What is the Average Order Value (AOV)?
- Which customers have not placed any orders?
- Which customers are repeat customers?
